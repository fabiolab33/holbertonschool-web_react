# TypeScript Project – Holberton School Web React

This repository contains a series of TypeScript exercises focused on learning advanced TypeScript features such as interfaces, classes, namespaces, ambient declarations, and nominal typing.

---

## 📁 Project Structure

The project is divided into multiple tasks:

- task_0
- task_1
- task_2
- task_3
- task_4
- task_5


Each task builds on the previous one and introduces new TypeScript concepts.

---

## ⚙️ Requirements

- Node.js
- npm
- TypeScript
- Webpack

Each task includes its own configuration files:
- `package.json`
- `tsconfig.json`
- `webpack.config.js`

---

## 🚀 How to Run

Inside each task folder:

### Install dependencies
```bash
npm install
```
### Build the project
```bash
npm run build
```

---

## 📚 Tasks Overview

| Task | Title | Description |
|------|------|-------------|
| Task 0 | Basic Interfaces | Create `Teacher` and `Directors` interfaces, use readonly and optional properties, and implement a function type. |
| Task 1 | Classes & Interfaces | Create `StudentClass` with methods `workOnHomework()` and `displayName()`. |
| Task 2 | Advanced Types | Create `Director` and `Teacher` classes, implement `createEmployee`, and use union types. |
| Task 3 | Ambient Namespaces | Define interfaces and types, use declaration files (`.d.ts`), and simulate external CRUD library integration. |
| Task 4 | Namespaces | Create a `Subjects` namespace with `Cpp`, `React`, and `Java` classes using declaration merging. |
| Task 5 | Nominal Typing | Create branded types (`MajorCredits`, `MinorCredits`) and implement safe arithmetic functions. |
